① 먼저 내 컴퓨터를 확인합니다

아무것도 모르셔도 괜찮습니다. 아래 순서대로 하나씩 확인하세요.

처음이라면 여기부터 시작하세요.
지금은 서버를 설치하지 않습니다. 먼저 “내 컴퓨터에서 서버를 실행할 준비가 되었는지” 확인합니다. 아래 항목을 1번부터 4번까지 차례대로 확인하세요.

1. Windows 버전 확인

이 사이트는 Windows PC에서 Minecraft Java Edition 서버를 여는 방법을 기준으로 설명합니다.

  1. 키보드에서 Windows 키를 누릅니다.
  2. 검색창에 winver라고 입력합니다.
  3. Enter를 누릅니다.
  4. “Windows 정보” 창이 나오면 Windows 버전을 확인합니다.

Windows 10 또는 Windows 11이라면 이 사이트의 Windows 설명을 그대로 따라가시면 됩니다.

2. Java가 설치되어 있는지 확인

마인크래프트 서버는 Java라는 프로그램이 필요합니다. 먼저 설치되어 있는지 확인합니다.

  1. 키보드에서 Windows 키를 누릅니다.
  2. cmd라고 입력합니다.
  3. 검색 결과의 명령 프롬프트를 클릭합니다.
  4. 검은색 창이 나오면 아래 명령을 그대로 입력하고 Enter를 누릅니다.
java -version
정상적인 경우: java version 또는 비슷한 문장이 표시됩니다.
오류가 나오는 경우: 'java'은(는) 내부 또는 외부 명령...처럼 나온다면 Java가 없거나 PATH 설정이 되어 있지 않은 것입니다.

중요: Java 버전은 Minecraft 버전에 따라 다릅니다. “최신 Java를 무조건 설치”하지 말고, 아래 서버 구동기 선택 단계에서 사용할 Minecraft 버전에 맞는 Java를 확인하세요.

3. RAM(메모리) 확인

RAM은 서버가 월드와 플레이어 정보를 처리할 때 사용하는 컴퓨터의 작업 공간입니다.

  1. Ctrl + Shift + Esc를 동시에 누릅니다.
  2. 작업 관리자가 열리면 왼쪽의 성능을 클릭합니다.
  3. 메모리를 클릭합니다.
  4. 오른쪽 위 또는 화면에 표시되는 전체 메모리 용량을 확인합니다.

예: 8.0GB, 16.0GB, 32.0GB 등으로 표시됩니다. 서버에 할당할 RAM은 컴퓨터 전체 RAM과 같게 설정하면 안 됩니다. Windows와 Minecraft 클라이언트도 RAM을 사용하기 때문입니다.

4. 서버를 저장할 공간 확인

  1. 키보드에서 Windows + E를 누릅니다.
  2. 왼쪽에서 내 PC를 클릭합니다.
  3. Windows가 설치된 드라이브(보통 C:)의 남은 공간을 확인합니다.

월드는 플레이하면서 계속 커질 수 있으므로 “지금 필요한 공간만 조금 있으면 된다”고 생각하지 마세요.

5. 공유기를 사용하고 있는지 확인

친구가 인터넷을 통해 서버에 접속하게 하려면 나중에 공유기 설정이 필요할 수 있습니다.

  1. 인터넷을 연결하는 장비를 찾습니다.
  2. 집에 인터넷 모뎀과 Wi-Fi 공유기가 따로 있다면 두 장비가 있는지 확인합니다.
  3. 공유기가 2대 이상 연결되어 있다면 포트포워딩이 조금 더 복잡해질 수 있으므로 나중에 이중 NAT 부분을 확인합니다.
모르겠다면: 지금 당장 공유기 모델명을 알아낼 필요는 없습니다. 서버 설치를 먼저 진행한 뒤 인터넷 접속 단계에서 다시 확인하면 됩니다.

컴퓨터 확인이 끝났다면

이제 다음 단계에서 어떤 서버 프로그램을 사용할지 결정합니다.

② 서버 구동기를 선택합니다

“서버 구동기”는 마인크래프트 서버를 실제로 실행해 주는 프로그램입니다.

완전 처음이라면: 아래의 Paper를 선택하세요. 이 사이트의 이후 설명도 Paper를 기준으로 진행합니다.
초보자 추천

Paper

Paper는 Minecraft 서버를 실행하는 프로그램입니다. 플러그인을 사용하기 쉽고 성능 개선 기능도 있어서 처음 서버를 만드는 사람에게 적합합니다.

이 사이트에서 선택할 것: Paper
다음 단계부터는 “Paper 서버를 Windows PC에서 여는 방법”을 설명합니다.
고급 선택

Folia

여러 영역을 병렬로 처리하는 방식이 Paper와 다릅니다.

처음 서버를 여는 분께는 권장하지 않습니다. 특히 Paper 플러그인이 모두 Folia에서 정상 작동한다고 생각하면 안 됩니다.

Folia를 선택하려는 특별한 이유가 없다면 Paper로 시작하세요.
설정이 많은 서버

Purpur

Paper를 기반으로 더 많은 설정과 게임플레이 관련 옵션을 제공하는 서버 구동기입니다.

처음에는 Paper로 서버를 열고, 나중에 필요한 기능이 생겼을 때 Purpur를 알아보는 방법이 가장 이해하기 쉽습니다.

어떤 것을 선택해야 하나요?

처음 서버를 엽니다
Paper를 선택하세요.
Folia를 꼭 써야 하는 이유가 있습니다
Folia 공식 문서와 플러그인 호환성을 먼저 확인하세요.
Paper보다 더 많은 설정이 필요합니다
Purpur를 검토하세요.

③ Paper 서버를 설치합니다

지금부터는 실제로 클릭하고 입력하면서 따라 하시면 됩니다.

작업하기 전에: 아래 예시에서 1.21.x 같은 버전은 예시입니다. 여러분이 플레이할 Minecraft 버전을 먼저 정하고, 그 버전과 호환되는 Paper 파일을 다운로드하세요.
1

서버 전용 폴더를 만듭니다

  1. 키보드에서 Windows + E를 누릅니다.
  2. 내 PC를 클릭합니다.
  3. 서버를 저장할 드라이브를 엽니다. 처음이라면 C: 드라이브를 사용해도 됩니다.
  4. 빈 곳에서 마우스 오른쪽 클릭 → 새로 만들기 → 폴더를 클릭합니다.
  5. 폴더 이름을 MinecraftServer로 입력하고 Enter를 누릅니다.

완료 후: C:\MinecraftServer 폴더가 있어야 합니다.

2

Paper 다운로드 페이지를 엽니다

  1. 아래 공식 사이트를 엽니다.
  2. 원하는 Minecraft 버전을 찾습니다.
  3. 해당 버전에 맞는 최신 Paper 빌드를 선택합니다.
  4. 다운로드한 .jar 파일을 아까 만든 MinecraftServer 폴더 안으로 이동합니다.
Paper 공식 다운로드 열기 ↗
다운로드한 파일의 이름을 확인하세요. 이후 명령어의 paper.jar 부분은 실제 파일 이름으로 바꿔야 합니다.
3

서버를 처음 실행합니다

가장 쉬운 방법은 서버 폴더에서 명령 프롬프트를 여는 것입니다.

  1. MinecraftServer 폴더를 엽니다.
  2. 파일 탐색기 위쪽의 주소 표시줄을 클릭합니다.
  3. 주소 표시줄에 cmd라고 입력합니다.
  4. Enter를 누릅니다.
  5. 검은색 명령 프롬프트 창이 뜨면 아래 명령을 입력합니다.
java -Xms2G -Xmx4G -jar paper.jar --nogui

주의: 실제 JAR 이름이 paper-1.21.x-xxx.jar라면 paper.jar 부분도 그 이름으로 바꿔야 합니다.

RAM 숫자는 예시입니다. -Xmx4G는 서버가 최대 4GB까지 사용하도록 한다는 뜻입니다. 컴퓨터 RAM이 8GB라고 해서 무조건 4GB를 서버에 할당하면 안 됩니다.
4

첫 실행 결과를 확인합니다

처음 실행하면 서버가 파일을 만들다가 EULA에 동의하지 않았다는 내용과 함께 종료될 수 있습니다.

이때 당황하지 마세요. 오히려 정상적인 첫 단계입니다.

  1. 명령 프롬프트를 닫아도 됩니다.
  2. 서버 폴더로 돌아옵니다.
  3. eula.txt 파일이 생겼는지 확인합니다.
5

EULA에 동의합니다

  1. eula.txt를 더블클릭합니다.
  2. 메모장으로 파일이 열립니다.
  3. eula=false라는 줄을 찾습니다.
  4. 동의할 경우 false를 true로 바꿉니다.
  5. Ctrl + S를 눌러 저장합니다.
  6. 메모장을 닫습니다.
중요: EULA 내용에 동의하는 경우에만 true로 바꾸세요.
Minecraft EULA 확인 ↗
6

서버를 다시 실행합니다

아까 열었던 명령 프롬프트에서 실행 명령을 다시 입력합니다.

java -Xms2G -Xmx4G -jar paper.jar --nogui

이번에는 서버가 계속 실행되면서 로그가 올라가야 합니다.

성공 여부 확인: 콘솔에서 서버가 완전히 시작되었다는 메시지가 나오면 다음 단계로 넘어갑니다. 오류가 빨간색으로 표시되면 그 문장을 지우지 말고 그대로 확인하세요.

지금 서버에 내 컴퓨터로 접속해 보기

외부 공개 설정을 하기 전에 먼저 서버 자체가 정상적으로 작동하는지 확인하는 것이 좋습니다.

  1. Minecraft Java Edition을 실행합니다.
  2. 멀티플레이를 클릭합니다.
  3. 서버 추가를 클릭합니다.
  4. 서버 주소에 localhost를 입력합니다.
  5. 완료를 누릅니다.
  6. 목록에서 방금 추가한 서버를 선택하고 서버 접속을 클릭합니다.
localhost 접속 성공: 서버 프로그램 자체는 정상적으로 실행되고 있는 것입니다. 이제 설정 → 플러그인 → 외부 접속 순서로 진행하면 됩니다.

④ 서버 기본 설정을 바꿉니다

server.properties는 서버의 기본 동작을 정하는 설정 파일입니다.

먼저 파일을 여는 방법

  1. 서버를 실행하고 있다면 명령 프롬프트에서 stop을 입력하고 Enter를 누릅니다.
  2. MinecraftServer 폴더를 엽니다.
  3. server.properties를 찾습니다.
  4. 더블클릭하면 메모장에서 열립니다.
  5. 원하는 값을 수정한 뒤 Ctrl + S로 저장합니다.
  6. 다시 서버를 실행합니다.
초보자 팁: 모르는 설정은 건드리지 마세요. 아래에서 설명하는 항목부터 하나씩 바꾸는 것이 안전합니다.

자주 바꾸는 항목

motd
서버 목록에 표시되는 서버 설명입니다. 예: 친구들과 생존 서버
max-players
동시에 들어올 수 있는 최대 인원입니다. 예: 10
gamemode
survival, creative 등 게임 모드를 정합니다.
difficulty
peaceful, easy, normal, hard 중 하나를 사용합니다.
white-list
true로 하면 허용한 플레이어만 들어올 수 있습니다. 친구끼리 하는 서버라면 유용합니다.
server-port
Java Edition의 기본 포트는 25565입니다. 포트포워딩을 할 때 이 번호를 사용합니다.
online-mode
처음이라면 true 그대로 두세요. 특별한 이유 없이 끄면 인증과 보안 문제가 생길 수 있습니다.
server-ip
보통 비워 둡니다. 초보자가 자신의 IP 주소를 여기에 입력할 필요는 없습니다.

설정 예시를 만들어 보기

아래 값은 “이렇게 설정할 수도 있다”는 예시입니다. 값을 입력하고 버튼을 누르면 파일에 넣을 줄을 만들어 줍니다.

motd=친구들과 생존 서버 max-players=10 gamemode=survival difficulty=normal simulation-distance=8 view-distance=8 white-list=false server-port=25565

설정 후 확인하는 방법

  1. 파일을 저장합니다.
  2. 서버를 다시 실행합니다.
  3. Minecraft의 멀티플레이 서버 목록에서 바뀐 서버 이름이나 설정을 확인합니다.
  4. 문제가 생기면 방금 바꾼 설정을 먼저 되돌려 봅니다.

⑤ 플러그인을 설치합니다

플러그인은 서버에 새로운 기능을 추가하는 작은 프로그램이라고 생각하면 쉽습니다.

가장 중요한 규칙: 플러그인 파일(.jar)을 plugins 폴더에 넣은 뒤 서버를 다시 실행합니다. 서버가 실행 중일 때 파일을 마구 넣지 마세요.
Bedrock 접속

GeyserMC

Java Edition 서버에 Bedrock Edition 플레이어가 접속할 수 있도록 해 주는 프로그램입니다.

설치 순서

  1. Paper 서버를 완전히 종료합니다. 콘솔에 stop을 입력하고 Enter를 누르세요.
  2. Geyser의 공식 설치 문서를 엽니다.
  3. Paper/Spigot용 Geyser 플러그인을 다운로드합니다.
  4. .jar 파일을 서버 폴더 안의 plugins 폴더에 넣습니다.
  5. 서버를 다시 실행합니다.
  6. 콘솔에서 Geyser가 로딩되었다는 메시지를 확인합니다.
  7. 생성된 Geyser 설정 파일에서 Bedrock 접속 포트를 확인합니다.
Geyser 공식 설치 문서 ↗
중요: Bedrock 접속에는 Java 서버의 TCP 25565와 별도로 Geyser가 사용하는 UDP 포트가 필요할 수 있습니다. 공유기와 Windows 방화벽에도 해당 UDP 포트를 설정해야 합니다.
청크 미리 생성

Chunky

플레이어가 처음 가는 지역의 청크를 미리 만들어 두는 플러그인입니다.

설치 순서

  1. 서버를 종료합니다.
  2. Chunky의 공식 배포 페이지에서 서버 버전에 맞는 파일을 다운로드합니다.
  3. 다운로드한 .jar를 서버의 plugins 폴더에 넣습니다.
  4. 서버를 다시 실행합니다.
  5. 콘솔에서 Chunky가 로딩되었는지 확인합니다.
  6. 게임 또는 콘솔에서 아래 명령을 사용합니다.
chunky radius 5000 chunky start

5000은 반경 예시입니다. 숫자가 클수록 만들어야 할 영역이 크게 늘어납니다.

처음에는 작은 숫자로 테스트하세요. 큰 범위를 한 번에 생성하면 CPU, 디스크, 시간이 많이 필요할 수 있습니다.
Chunky 공식 위키 ↗

플러그인을 설치했는데 안 보인다면

  1. 파일이 정말 plugins 폴더 안에 있는지 확인합니다.
  2. 파일 확장자가 .jar인지 확인합니다.
  3. 압축 파일을 그대로 넣은 것은 아닌지 확인합니다.
  4. 서버를 재시작했는지 확인합니다.
  5. 콘솔의 오류 메시지를 확인합니다.
  6. 플러그인이 현재 Minecraft/Paper 버전을 지원하는지 확인합니다.
  7. 플러그인에 필요한 다른 플러그인(의존성)이 있는지 확인합니다.

⑥ 친구가 인터넷으로 접속하게 만들기

이 부분이 처음에는 가장 어려울 수 있습니다. 순서를 절대 건너뛰지 마세요.

먼저 확인: 지금까지의 과정에서 Minecraft Java Edition으로 localhost 접속이 성공해야 합니다. localhost도 안 되면 인터넷 설정을 하기 전에 서버 자체부터 해결해야 합니다.

1단계 — 서버 PC의 내부 IP 주소 찾기

  1. 서버를 실행하는 PC에서 Windows 키를 누릅니다.
  2. cmd를 입력합니다.
  3. 명령 프롬프트를 클릭합니다.
  4. 아래 명령을 입력하고 Enter를 누릅니다.
ipconfig
  1. IPv4 주소라고 적힌 줄을 찾습니다.
  2. 예를 들어 192.168.0.50이라고 되어 있다면 이 숫자를 적어 둡니다.
이 숫자는 무엇인가요?
이것은 인터넷 전체에서 사용하는 주소가 아니라 집 안에서 서버 PC를 찾기 위한 주소입니다. 포트포워딩에서 이 주소를 사용합니다.

2단계 — Windows Defender 방화벽에서 25565 허용

Windows가 인터넷에서 들어오는 Minecraft 연결을 차단하지 않도록 인바운드 규칙을 만듭니다.

  1. Windows 키를 누릅니다.
  2. 검색창에 고급 보안이 포함된 Windows Defender 방화벽을 입력합니다.
  3. 검색 결과를 클릭합니다.
  4. 새 창의 왼쪽에서 인바운드 규칙을 클릭합니다.
  5. 오른쪽에서 새 규칙...을 클릭합니다.
  6. 포트를 선택하고 다음을 클릭합니다.
  7. TCP를 선택합니다.
  8. 특정 로컬 포트에 25565를 입력합니다.
  9. 다음을 클릭합니다.
  10. 연결 허용을 선택하고 다음을 클릭합니다.
  11. 프로필 선택 화면에서는 현재 사용하는 네트워크에 맞는 프로필을 확인합니다. 일반적인 가정용 네트워크라면 개인 프로필을 사용하는 경우가 많습니다.
  12. 다음을 클릭합니다.
  13. 이름에 Minecraft Server TCP 25565라고 입력합니다.
  14. 마침을 클릭합니다.
완료 확인: 인바운드 규칙 목록에서 방금 만든 Minecraft Server TCP 25565 규칙을 찾을 수 있으면 됩니다.
Geyser를 사용할 경우: Geyser의 Bedrock 포트는 UDP를 사용합니다. Geyser 설정에 표시된 UDP 포트에 대해서도 같은 방식으로 별도의 인바운드 규칙을 만들어야 할 수 있습니다.

3단계 — 공유기 관리 페이지 열기

포트포워딩은 Windows가 아니라 공유기 설정 화면에서 합니다.

  1. 공유기에 연결된 PC에서 인터넷 브라우저를 엽니다.
  2. 공유기 제조사에서 안내하는 관리자 페이지 주소를 입력합니다. 주소는 공유기마다 다릅니다.
  3. 로그인 화면이 나오면 공유기 관리자로 로그인합니다.
  4. 메뉴에서 포트포워딩 / 포트 포워딩 / Port Forwarding / NAT / 가상 서버처럼 표시된 메뉴를 찾습니다.
주의: 공유기 관리자 비밀번호를 이 사이트에 입력할 필요는 없습니다. 여기에는 비밀번호를 입력하지 마세요. 공유기 설명서나 제조사 공식 문서를 이용해 메뉴 위치를 확인하세요.

4단계 — 25565 포트포워딩 만들기

공유기 화면의 항목 이름은 제조사마다 조금씩 다릅니다. 다음 값이 핵심입니다.

서비스 이름
Minecraft 등 알아보기 쉬운 이름
외부 포트
25565
내부 포트
25565
내부 IP / 서버 IP
앞에서 찾은 서버 PC의 IPv4. 예: 192.168.0.50
프로토콜
TCP

값을 입력한 뒤 적용 / 저장 / 확인처럼 표시된 버튼을 클릭합니다.

가장 흔한 실수: 서버 PC의 IP를 잘못 입력하거나, 외부 포트와 내부 포트를 다르게 입력하거나, UDP로만 설정하는 것입니다.

5단계 — 서버를 실행합니다

  1. Windows에서 Minecraft 서버를 다시 실행합니다.
  2. 콘솔 창이 계속 켜져 있도록 합니다.
  3. 서버가 완전히 시작되었는지 확인합니다.
중요: 포트 검사 사이트는 실제로 해당 포트에서 연결을 받을 서버가 실행 중이어야 “열림”으로 확인되는 경우가 많습니다.

6단계 — 25565가 인터넷에서 열렸는지 확인합니다

이제 외부 포트 검사 사이트에서 25565를 검사합니다.

PortChecker.co 포트 검사 사이트입니다.

PortChecker 열기 ↗

사이트에서 포트 번호에 25565를 입력하여 검사하세요.

CanYouSeeMe 외부에서 특정 포트에 연결할 수 있는지 확인하는 사이트입니다.

CanYouSeeMe 열기 ↗

포트 번호에 25565를 입력하여 검사하세요.

OPEN이 나오면: 외부에서 25565 포트까지 연결이 도달하고 있을 가능성이 높습니다.
CLOSED가 나오면: 아래 순서대로 다시 확인하세요.
① 서버가 실행 중인가?
② Windows 방화벽 규칙이 켜져 있는가?
③ 포트포워딩의 내부 IP가 현재 서버 PC의 IPv4와 같은가?
④ 외부/내부 포트가 25565인가?
⑤ 공유기가 2대라면 이중 NAT인가?
⑥ 통신사가 CGNAT를 사용하고 있는가?

7단계 — 친구에게 알려줄 주소

친구가 다른 집에서 접속한다면 보통 공인 IP 주소와 포트를 사용합니다.

형식은 다음과 같습니다.

공인IP:25565

예: 123.123.123.123:25565

공인 IP를 이 사이트에 입력할 필요는 없습니다. 친구에게 서버 주소를 알려줄 때만 사용하면 됩니다. 서버를 공개할 때는 화이트리스트와 온라인 인증을 사용하는 것을 권장합니다.

공유기가 2대라면?

예를 들어 다음처럼 연결되어 있다면:

인터넷 ↓ 공유기 A ↓ 공유기 B ↓ 서버 PC

포트포워딩을 한 번만 설정해서는 안 될 수 있습니다. 첫 번째 공유기에서 두 번째 공유기로, 두 번째 공유기에서 서버 PC로 연결을 전달해야 하는 구조가 됩니다.

또한 공유기의 WAN/인터넷 주소가 10.x.x.x, 172.16.x.x~172.31.x.x, 192.168.x.x 등의 사설 IP라면 상위 NAT가 존재할 가능성이 있습니다.

CGNAT: 통신사가 가입자에게 공인 IPv4를 직접 주지 않는 환경에서는 일반적인 포트포워딩만으로 외부 접속이 불가능할 수 있습니다. 이 경우 통신사에 공인 IPv4 제공 여부를 문의하거나 다른 서버 공개 방법을 검토해야 합니다.
